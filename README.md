# Notice Board CRUD Application

A full-stack Notice Board application built using Next.js, Prisma, and MySQL.

## Features

- Create Notice
- View Notices
- Edit Notice
- Delete Notice
- Notice Category
- Priority
- Publish Date
- Optional Image URL

## Tech Stack

- Next.js
- React
- Prisma ORM
- MySQL
- JavaScript

## Installation

```bash
npm install
```

Run Prisma:

```bash
npx prisma generate
npx prisma db push
```

Start the application:

```bash
npm run dev
```
